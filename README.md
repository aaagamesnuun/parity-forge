# Parity Forge

**非対称アブストラクトゲームを、有限の計算予算で発見・検証する研究システム。**
完成したゲームの集合ではありません。アイデアを機械可読なルールにし、
合法手・終局・AI対戦・厳密解析を分離して調べ、失敗も再利用できる形で残します。

引き継ぎません。過去の「次に実行する」をそのまま実行しないでください。

## 固定条件と仮説

- 2人・決定論的・完全情報で、役割のメカニクスが非対称である。
- **全ての合法なプレイが有限手で終了し、必ず片方だけが勝つ。引き分けなし。**
- **「最後に置けなかったほうが負け」および実質的に同じ勝敗条件は禁止。**
- 盤面の小ささ・極端なルールの簡単さは必須ではない。公平性・深さ・分かりやすさを評価する。

「自分の判断で負け、理解すれば次は勝てそうだと思えるゲーム」を目指しています。
弱いAIの勝率50%や探索打ち切りを、公平性・奥深さの証明とは扱いません。
計算上の `UNKNOWN` はゲームの引き分けでも敗北でもありません。

## 現在地（2026-09-10 の共有時点）

DSL、決定論的エンジン、エージェント、厳密ソルバー、評価・証拠保存の基盤はあります。
ただし、**公平性・深さ・面白さが確認された新ゲームはまだありません。**

初期の「配置対移動」から、より広い行動の組合せ、捕獲・競走、cut-and-choose、
有限空間ゲームを経て、Plan40では9×9接続ゲーム「架橋と転色」を検証中です。
接続を勝利目的にした新候補の実装は技術的に受け入れ済みですが、品質認定ではありません。
元研究環境の全回帰は1,552件成功（意図したskip 2件）。共有コピーの検証範囲は下記と
[共有範囲](docs/team/SHARING_SCOPE_JA.md)を参照してください。

既存の[キャッチアンドジャンプ](https://catch-and-jump.realnuun.chatgpt.site/)は
以前のI/L試作です。新候補とは別で、今の除外条件を満たす発見として推奨しません。
[ゲームコードのみのリポジトリ](https://github.com/aaagamesnuun/catch-and-jump-analysis)も別管理です。

## 最小の動作確認

Python 3.9以上。外部Python依存・モデルAPIキー・パッケージのインストールは不要です。
リポジトリのルートで実行します。

```sh
PYTHONPATH=src python3 -m parity_forge --help
PYTHONPATH=src python3 -m unittest tests.test_connection tests.test_connection_search -v
```

上のテストは小さな合成局面だけを使い、登録済み9×9対戦や本番バッチを再実行しません。
共有コピーの動作確認は、本番の実験予算や品質評価とは別です。

研究元環境でのコード変更時の全回帰コマンドは以下です。
履歴データ・元Git履歴を省いた共有コピーでは一部の統合テストを実行できません。
初回参加時に約90分の全回帰や履歴復元を開始する必要はありません。

```sh
PYTHONPATH=src python3 -m unittest discover -s tests -v
```

詳細は[資料目次](docs/INDEX.md)。未共有の生データを必要とする再現実験は、
所有者とデータ範囲・新しい実験ID・予算を決めてから行います。

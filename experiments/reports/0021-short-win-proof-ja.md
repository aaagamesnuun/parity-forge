# キャッチアンドジャンプ候補：A先手の簡単な必勝法

2026-09-06。結論：Plan21のA先手版を人間試遊への推薦から外す。
分類はTRIVIAL_FORCED_RESULT / SINGLE_STRATEGY。Aは4回の自分の手番、
全体7手以内で勝てる。相手の最初の移動先に応じた一度の分岐だけでよい。
固定実験のUNKNOWNとTRIAL_REVIEW_ONLYは当時の機械出力として変更しない。

対象はdefinition_hash
a5e674e625aa0d2cac9858ef288e96d68ca68799801d7a4e8d12dc29139efe4c。
機械定義はcapture-hop-full-ranks-v0.jsonのA先手版。
以下の座標はエンジンと同じ0始まり、上辺がrow0、下辺がrow4。

## 方策

1. Aは(0,0)から(1,1)へ進む。
2. Bの最初の手は必ずrow4からrow3への1歩。着地点を(3,b)とする。
3. Aは同じ駒を、b=0なら(2,2)、それ以外なら(2,0)へ進める。
4. 以後もその駒だけを、同じ列のrow3、row4へ直進させる。Bがいれば捕獲する。

## 全応手に対する証明

Aの2手目終了時、Bは1枚だけrow3にあり、残りはrow4。
Aの前進駒を(2,x)とすると、Bのrow3の駒がそれを飛び越す着地列は2x−b。

| Bの最初の着地列b | Aが選ぶ列x | Bの飛び越しが成立しない理由 |
|---|---|---|
| 0 | 2 | 列差2で隣接していない |
| 1 | 0 | 隣接するが着地列−1は盤外 |
| 2,3,4 | 0 | 隣接していない |

row4の別のBが友軍を飛び越してもrow2まで。したがってBの2手目終了後、
すべてのBはrow2以下にとどまる。Aが3手目にrow3へ進んだ後、row1は完全に空。
Bの3手目にrow2からrow0へ跳ぶにはrow1の踏み台が必要だが存在しない。
row3以下のBも1手でrow0に届かない。よってBはAの4手目より先に到達できない。

Aの他の駒はrow0から動かないので、選んだ駒の進路に味方はいない。
BはAを捕獲・押し戻しできず、Aは空きにもBのいるマスにも前進できる。
したがってAは必ず4手目にrow4へ到達する。途中でBが行動不能なら、さらに早くAが勝つ。
目標到達はエンジンの手数制限判定より先であり、全体7手は上限41より小さい。

## 検証と判断

発見担当と独立監査担当が、それぞれ既存ソースと定義だけから全応手の行・列条件を確認。
rootも独立に同じ場合分けを確認した。追加の対局、engine、solver、replay呼出は0。
数学的論証の追加であって、過去の未完了完全解析を成功に書き換えるものではない。

浅いAIの各4局で両役が勝つことは、この簡単な方策を排除しなかった。
この候補に強いAIの追加対戦や予算増量を行う価値はない。B先手は別条件であり、
本証明は適用しないが、元から試遊判定を通っていない。現在、人間に薦める候補は0。
サイト制作・試遊依頼は保留。次は別の小さな設計を、単純必勝法と複数方策・強度の
偏りを先に確認する固定・有限の検証へ進める。完全公平性や奥深さの証明とは区別する。

## Objective

Turn Plan 0012's supported broad-family substrate into one bounded, immutable,
equal-family development atlas. Freeze membership and evaluation rules from
outcome-free evidence first; then use exact solving, family-compatible sampled
agents, and replay telemetry to determine whether any of six mechanically
asymmetric occupancy families contains a nontrivial candidate shape.

This is a development experiment, not confirmation and not a prevalence study.
It may identify a family frontier worth deeper search, but it cannot establish
that a family is generally good or that a surviving game is enjoyable.

## Observation

The old `A = PLACE / B = MOVE` lane and its capture/two-runner variations produced
mechanical engagement without a non-dominant candidate. Plan 0012 therefore added
strict PUSH, SWAP, HOP, CONVERT, reused MOVE_CAPTURE, and ELIMINATE semantics plus
replay-derived telemetry.

The outcome-free census reconstructed 214,368 exact inputs and 102,336 D4 orbits.
All six provisional cells have eligible support, but only the 3+3 setup forms a
common grid across every family, goal frame, ordered vector pair, and first
player. That core has 88 member strata, which form 44 matched first-player-paired
strata with at least 12 eligible D4 setup pairs per paired stratum.
The census contains no evidence about exact value, sampled fairness, strategic
quality, or enjoyment.

## Hypothesis

A mechanically broader but structurally matched 3+3 portfolio is more likely than
the old placement-versus-runner topology to contain reciprocal, non-dominant play.
If all six cells still fail under exact and multi-strength evidence, the result
will retire only this exact six-signature 3×3 core and justify another bounded
portfolio or board-size hypothesis rather than more parameter tuning inside it.

## D4 orientation policy

Exact value is solved once per member and not repeated across its eight
orientations because each member's value is D4 invariant. Pair analysis retains
the full ordered
`(A-first value, B-first value)` matrix so role dominance, first-player dominance,
second-player dominance, and horizon-containing pairs remain distinct. Any
coordinate-tie-sensitive sampled agent is evaluated under all eight declared D4
group actions for both members of every selected pair. Each member receives eight
scheduled orientation slots even when a stabilizer makes two transformed
definitions byte-identical; this keeps pair-level nominal exposure equal and the
duplicate relation is reported. Alternatively, a sampled agent may omit the
eight-way schedule only after a finite, independently reviewed proof that its
action distribution is D4-equivariant for the complete atlas vocabulary.

## Evaluator compatibility before the atlas run

The exact solver and seeded random agent operate through the generic engine, but
the existing goal-progress and minimax heuristics deliberately reject ELIMINATE.
They are also not cross-family calibrated on REACH versus CONNECT, and the
goal-directed policy does not assign an explicit losing utility when its action
immediately satisfies the opponent's schema-v4 goal. Do not bypass those guards
or compare families with different agent algorithms.

Before production play, create a frozen schema-v4 evaluator benchmark spanning
all five active action kinds, all three goal kinds, actor/opponent terminal
priority, forced wins/losses/draws, nonterminal cutoffs, D4 transforms, node
budgets, and deterministic tie handling. Use it to establish one common bounded
agent ladder. The preferred minimal baseline is a terminal-only depth-limited
search with exact terminal utility, zero-valued nonterminal cutoff, canonical
legal actions, seeded tie resolution, fresh-agent lifecycle, and cumulative node
accounting. It is intentionally weak but family-neutral. Any richer heuristic is
a separately versioned evaluator change tested on a frozen benchmark, not tuned
silently against atlas outcomes.

Agent strength must remain descriptive until exact-direction accuracy and D4
behavior are measured. A 50/50 weak-agent split cannot establish fairness.

The new search ladder uses one algorithm family/version across all depths and
both roles, while recording depth in each strength identity. It uses an
independent fresh instance and equal cap for every
`definition × orientation × strength × controlled role` slot, one reset before
its fixed seed sequence, and a per-slot cumulative node ledger. A different
lifecycle is allowed only after a reviewed proof of exact role symmetry. Budget
exhaustion retains every completed game plus the current reproducible prefix; it
cannot replace or reroute the slot.

D4 disagreement in the engine, definition transform, replay transform, or exact
solver value invalidates the run. Variation in a coordinate-tie-sensitive
sampled agent's actions or results is instead descriptive orientation
sensitivity and remains visible; it is not pooled as an engine error.

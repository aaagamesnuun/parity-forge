# 共有範囲と再現性の境界

この共有版は元研究環境の丸ごとのバックアップではなく、メンバーが意図を理解して
コードレビュー・限定的な開発を始めるための、履歴なしのスナップショットです。

## 含めるもの

- Pythonのシステム本体、テスト、研究用補助コード、過去の実験スクリプト。
- README、AGENTS.md、思想・分業の日本語ガイド、設計・決定・教訓・計画の文書。
- 選別した人間向け研究レポートと、未封印の提案・登録文書。
- 小さな静的DSL fixture（`experiments/corpora/static-v1/`）。
- `SHARE_MANIFEST.json`：収録ファイル、元と共有版のSHA-256、除外方針。

コードや凍結したルール定義はバイトを変えません。文書に含まれる個人のローカルパスは
共有コピーでのみ置換し、共有版の文書の冒頭には「元ホストの記録であり実行指示ではない」
旨を付けます。その差分はmanifestで明示します。元の記録は変更しません。
このため、文書の共有版を元実験のhash検証に使ってはいけません。

## 含めないもの

- 元の`.git`とその履歴、大量の`experiments/runs/`、保護されたPlan13/14の生の証拠・対象一覧。
- ログ、実行receipt、attempt、lock、予約、封印済み実行manifest、現在動作中のワーカー出力。
- 個人ホスト情報、認証情報、環境変数ファイル、ブラウザ／ホスティング管理情報。
- サイトの作業ディレクトリ、試作用依存パッケージ、外部タスクの会話全文。

古い文書内のリンクには、これら未収録の証拠を指すものがあります。
リンク先がないことは記録の不存在や再実行の許可を意味しません。
思想・経緯は読めますが、過去の全実験をこのrepo単体で独立再現できるとは主張しません。
共有スコープの拡張・生データの開示は、対象と目的を決めて所有者に相談します。

## 実行してよい最小確認

```sh
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m parity_forge --help
PYTHONDONTWRITEBYTECODE=1 PYTHONPATH=src python3 -m unittest -v tests.test_dsl tests.test_analysis tests.test_connection tests.test_connection_search tests.test_cut_choose tests.test_finite_space
```

これは共有版の移植確認です。本番の対戦、厳密解析、事前登録された研究を行いません。
`SHARE_VERIFICATION.json` に、この共有版で実際に観測した結果を保存します。
元の1,552テスト成功は元環境での技術的受入記録であり、共有版の全テスト成功ではありません。

履歴系は固定Gitコミットと大量の実験出力に依存します。`test_connection_batch` も
元環境のソースpin・登録・受入証拠が必要です。欠損を埋めるために
本番batch、`--seal`、古い実験scriptを走らせないでください。
ゲームの品質を判断する試験と、ソフトウェアのテストは分けて報告します。

## アクセス・権限

当初はメンバー向け非公開を推奨します。公開範囲とメンバー招待は所有者が決めます。
既存の公開ゲームとコード専用repoは、この共有作業で変更しません。
ライセンスは未指定です。共有の依頼からOSSライセンスや一般向け再配布許諾を推定しません。
共有版の変更を元研究環境へ戻す際はPRをレビューし、凍結ソースを上書きせず次の計画で扱います。

# ゲーム生成システムの共同計画 — 対話開始

2026-09-05。計画を反復して詰めるための記録。実装・実験の登録ではない。
既存手法で候補を探す別タスクのPlan20とは分けて扱う。

## ユーザーの意図

- アブストラクトゲームを発見するシステムを作りたい。
- まず計画を徹底的に二人で詰めたい。助手が案と論点を出し、ユーザーが
  考えて返答し、それを受けて助手が再検討する対話を繰り返す。
- 「非対称アブストラクトゲームが世の中に足りない」が第一の仮説。
  「条件は非対称なのに勝率が半々ならゲームとして成立する」という
  仮説も提示するが、これにとらわれない検討を認めている。
- 最終像は「Astraによるアイデアだしと、検証システムのループ」で、
  「トークンコストを払った分だけ」ゲームのルールを発見すること。

## 証拠から持ち込む前提

現在、全要件を満たすゲームは未発見。浅い対局の勝敗の散らばりは、
簡単な必勝筋や機能しない目標を見落とした。50%だけを合格条件にしない。
固定初期状態・有限・決定論・完全情報・無引分なら、完全最適プレイでは
片方に必勝戦略がある。公平性は比較可能な有限の実力について定義する。

Plan18は全合法進行の有限決着に成功したが、全定義が最大6手で終わり、
24条件が合計850状態で解けた。終了保証、容易な解析への抵抗、公平性、
面白さは別の主張として扱う。非対称作品の供給不足と、プレイヤーの需要は
別の未検証仮説。狭い内部実験から市場の有望性も全般の不可能性も導かない。
簡単なルールと奥深さ、上達できそうな敗戦からの再戦欲という既回答の
好みは引き継ぐ。D-055/D-057を維持する。

## 助手の提案 — 未合意

最初に「誰が、どの程度両役を覚えたときに、公平であってほしいか」を
考える。中心仮説は、両役を覚えた二人が繰り返し遊び、上達していく場面。
これは対象とする遊ばれ方であり、その二人の通算50%を公平性の証明に
使うという意味ではない。役割・先手条件、方策・強さの違いは別々に見る。

対話の順序案は、対象プレイヤーと遊ばれ方 → 非対称性が生む判断の違い →
発見の合格線と人間の判断範囲 → 自動検証とAstraの分担 → 小さな比較実験。
一度に全項目への回答を求めず、返答に応じて順序や仮説を修正する。

システム案は、少数のルール骨格と相互作用の仮説をAstraが提案し、DSLで
意味を確定した後、通常プログラムが検証し、失敗理由と代表例をまとめて
Astraへ返す反復。人間は残った候補の遊ぶ価値を判断する。
毎局のLLM呼出しや候補ごとの専用基盤を前提にしない。

「生成定義数」「重複を除いた機械検査通過候補」「人が再戦したい作品」を
区別し、モデル費用・計算費用・人の評価時間を別記する。追加支出から
必ず発見が出るとは約束しない。方法の改善は、評価器などを固定した
単純生成との比較で測る。予算切れのUNKNOWNを難しさや合格に数えない。

上記は初回応答時点の提案。ユーザーの返答による修正を次節に記す。

## 第2往復 — ユーザーの目的の明確化

ユーザーの回答原文：

> 1. 将棋棋士が遊べる程度の深さ。そこまでの深さが難しければ、俺と友達が遊べる程度の深さ。
> 2. 非対称性によって判断の違いを作りたいわけじゃない。ゲームの潜在空間でまだ探索されてないから掘りたいだけ。
> 3. 最悪、完全に勝率が半々じゃなくても良い。習熟する過程が楽しい程度には深ければいい。検証できる深さを定義して、それを満たせるようにしたい。
> 4. 検証の段階でAIが強いことが大事なのかも。でもそれってむずいよなー

確定した目的の修正：

- 非対称性は未探索領域を掘るための探索仮説。助手が提案した
  「役割ごとの判断の違いを体験価値にする」はユーザーの要求ではない。
  未探索性自体も現時点では仮説であり、検証済みの新規性ではない。
- 中心目標は習熟の過程が楽しい深さ。正確な50%は必須ではなく、偏りは
  別途測って開示する。許容勝率や新しい合格閾値はまだ定まっていない。
- 将棋棋士が遊べる深さを目指すが、本人と友人が楽しめる深さも成果として
  認める。棋士並みのAIや特定の予算だけで前者を認定できるとは扱わない。
- 簡単なルール、全合法進行の有限・無引分決着は引き継ぐ。D-057の
  容易な完全解析への抵抗は撤回されていないが、それ自体は深さの正の証拠ではない。

次の助手案（深さの検証法と閾値は未合意）：

> 思考や学習を増やすと、より有効な判断を何段階も獲得でき、
> その改善が練習に使わなかった相手にも通用する余地を測る。

探索予算だけを増やす実験と、学習量を増やして一手の思考予算を固定する
実験は分ける。役割ごとに共通の固定相手群への改善を比較し、独立した
相手でも確認する。相性の循環を単一順位や自己対戦50%で消さない。
何段の差をどの確度で認めるかは、対照による校正後、候補評価前に定める。
AIの成績が伸びない場合は、ゲームの浅さと測定AIの能力不足を区別できず、
原則として未判定。予算切れにも深さの得点を与えない。

現在のterminal-only minimaxは非終端の探索打切り局面を0とする。
終局が視野に入らない場合、depth2→3だけでは実力差が生じないことがある。
最強の汎用AIを先に完成させるのでなく、安い単純戦略・探索で失敗を調べ、
残った少数へ独立方式や学習による追加評価を割り当てる案を検討する。
モデルのトークン費用、対局・学習計算費用、人間の評価時間は別に計上する。

機械的な解析困難さ、測定したAI群の上達の余地、人が楽しむ習熟は別物。
当面は前二者で候補を絞り、人間の経験で最後の主張を確かめる案。
この時点では具体的な上達経験を次に聞く案を出したが、次節のユーザー回答で
個人体験の質問と学習・転移の必須検査は取り下げた。

一次資料との照合（本プロジェクトでの検証結果ではない）：

- [Lantz et al., Depth in Strategic Games (2017)](https://www.nealen.net/papers/Lantz2017Depth.pdf)：
  計算資源に対する段階的な部分戦略の強化という概念モデル。人間の楽しさを
  自動的に証明する尺度や、実用的な完成済み判定器として提示されたものではない。
- [Goodman et al., Skill Depth in Tabletop Board Games (2024)](https://tabletopgames.ai/assets/pdf/Goodman2024SkillAnalysis.pdf)：
  予算の異なるAIによる測定と、AIの設定・方式による評価の大きな変化を報告。
  非対称・無引分の本候補へそのまま適用できる保証ではない。
- [GAVEL (2024)](https://arxiv.org/html/2407.09388v2)：
  言語モデルと段階的なゲーム評価の先行例。自動指標の達成と面白さを区別し、
  専門家の試遊を実施。本件のD-055に適合しない打切りのdraw扱いは採用しない。

## 第3往復 — 有限範囲の自明必勝検査へ絞る

ユーザーは個人的体験に基づく計画より、数学的・解析的・統計的な生成を
望む。「学ぶ価値」「特定相手への慣れではない」の独立検査は不要とし、
ある程度の深さまで自明な必勝を検証し、その先を本人が試す分担を選んだ。
「打つ手が自明じゃなければ良い」が当面の方針。「どういう方向の思考を
やらせたいか」は生成アイデアの書き方としては検討の余地がある。

この分担を採用する。深さがあれば学習・転移が自動的に生じるという仮説は
未証明だが、その真偽を自動検証の前提や追加ゲートにする必要はない。
個人体験を聞く質問は繰り返さず、勝率50%や学習曲線の検証も必須に戻さない。

助手の具体案は[有限自明必勝検査 v0](../designs/bounded-obvious-win-screen-v0.md)。
短手数の必勝、長くても単純な固定方針で勝てる場合、小予算の完全解析を
分ける。相手の全合法応答に対する証明、範囲限定の不在、予算切れを区別する。
例示上限は短手数2/4/6/8 ply・累計10万展開、各役最大4方針・各5万展開、
完全解析1回10万状態。校正前の議論用であり、登録・実行・閾値合意ではない。
次に詰めるのは単純方針の有限表現、証拠、計算量の数え方、対照例である。

## 第4往復 — 2026-09-06：ルール構造の仮説を先に考える

ユーザーは「必勝がすぐわからないようなルールの特徴についてまず考えるべき
なのかも」と提案した。検証システムの目的は維持し、その前段に生成側の
構造仮説を置く案を検討する。新しいルールや探索計画の採択ではない。

追加の既存証拠：Plan21は相手の初手に応じた一度の分岐と一駒の前進で
全体7手の必勝。Plan23は両端に走者を分け、守られていない側を進める
短い方策で全体11手以内に必勝。接触、多数の手、複数の脅威だけでは
簡単な攻略を除けず、短い探索範囲の外にも簡潔な方策が残る。
根拠：[Plan21証明](../../experiments/reports/0021-short-win-proof-ja.md)、
[Plan23証明](../../experiments/reports/0023-short-win-proof-ja.md)。
保存された論証を読むだけで、新しい候補評価や再実行はしていない。

助手の生成仮説（未検証、合格条件ではない）：

- 相手が本命の勝利経路へ有効に介入できる。接触の存在だけでなく、
  固定した一駒・一本道・最短前進などへの反撃が可能な構造を狙う。
- 同じ一手に利益と機会損失を持たせる。前進すると守備を離れる、
  捕獲すると相手の通路を開ける等、単純な優先順位が状況で裏目に出る。
- 一手が後の選択肢を変え、その変化を相手も使える。通路の形成・消費や
  駒の複数用途を案として考える。無関係な副作用や単なる待ち手は数えない。

終了を保証する単調な残量Phiと、各役の有利さは別の量でよい。
有限資源が減って必ず終わる一方、前進や捕獲の価値は局面で変わり得る。
終局保証を捨てたり、単純な一本道を長くすることを深さと呼んだりしない。
盤の大きさ・分岐数の増加だけでも深さは保証されない。

Astraの案には「壊したい簡単攻略」「それが失敗し得るルール上の理由」
「それでも残りそうな別の簡単攻略」「全合法進行の終了理由」を添える。
その後に有限検証を当てる。ある局面で作戦が悪手になるという例だけでは
初期局面からの必勝を反証できず、その作戦で到達可能な反例が必要。
小変更で一つの攻略を壊してもゲーム全体の深さは認定しない。

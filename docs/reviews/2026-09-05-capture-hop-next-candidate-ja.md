# 次候補：捕獲役と飛び越し役の前進競走

状態：未登録・未対戦の設計案。Plan20の追加対局でも、完成ゲームの認定でもない。
Plan20の全体テストをそのまま動かしている間の、データ・論証だけの準備。
新しい探索基盤、エンジン、AI、実験ランナーはこの準備では作らない。

## 正本と簡単なルール

[機械定義](../../experiments/proposals/capture-hop-full-ranks-v0.json)が正本。
5×5、A先手・B先手を別々の2定義として保存した。次の説明はその定義に従う。

1. Aの5枚を上辺の全マス、Bの5枚を下辺の全マスに並べる。
2. 毎手、自分の駒1枚を進める。Aは下向き、Bは上向き。
3. Aは前・斜め前へ1マス進む。空きマスへ進むか、そこにいるBを取れる。
4. Bも前・斜め前の空きマスへ1マス進める。そこに駒がある場合は、
   同じ方向のその先が盤内の空きマスなら、その駒を1枚だけ飛び越せる。
   飛び越す駒は敵味方どちらでもよく、取らない。連続ジャンプはしない。
5. どれか1枚を反対側の辺へ届けたら勝ち。合法手がなくなったら負け。

パス・運・引き分けはない。先手条件ごとの結果は混ぜない。
駒の枚数を勝率に合わせて事後調整する予定はなく、候補の追加も未登録。

## なぜこの候補か

Plan20では、押したBが直ちに捕獲されることと、初期配置の無防備な直通路が問題だった。
この案ではBはAを押し戻さず、自分が飛び越して先へ進む。Aは後退できないため、
飛び越された後に同じ駒でBを捕獲することはできない。
初期配置は両端を全部埋め、特定の空き列を作る複雑な配置選定を避ける。
ただし、後から生じる隙間や別の単純必勝法まで除けたとは主張しない。

A先手でも「1枚だけ一直線に進め続ける」案にはBの応手がある。
同じ列cで、A(0,c)→(1,c)、B(4,c)→(3,c)、A→(2,c)、
BがAを飛び越して(1,c)、A→(3,c)、B→(0,c)と進めばBが先着する。
これはAの特定の単純方策への反例であり、Bの万能必勝戦略ではない。
この手順はルールから手で確認した説明で、エンジンを使った追加対局ではない。

比較した別案は、Aの移動を下・右下、Bの押しを上・右上へ制限する変更。
斜め押しへの逆捕獲をなくせるが、盤の右端の影響を増やすため、今回は候補を増やさない。
選択は設計判断であり、両案の性能を測って比較した結果ではない。

## 全合法手順の決着

Phi＝A各駒の下辺までの行距離の和＋B各駒の上辺までの行距離の和。
Phiは非負整数で、初期値は5×4＋5×4＝40。

- Aの1歩で1減る。捕獲すれば、取ったBの非負の残距離も消える。
- Bの通常移動で1、飛び越しで2減る。他の駒の位置は変えない。

したがって全合法手でPhiが厳密に減り、40手以内に終端へ達する。
DSLのmax_pliesを41としているので、手数制限による引き分けには到達しない。
既存の目標到達・行動不能の規則により、必ず一方だけが勝つ。
これは終了の証明であり、戦略の深さ・公平性・面白さの証明ではない。

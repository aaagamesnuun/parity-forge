# 試遊ガイド：直線とL字

「人間が短く試す意味のあるルール候補」まで進みました。
まずは7×7版を1局。これは公平性・奥深さ・面白さの認定ではありません。
人間の試遊はまだ0件です。今回の候補は紙、または既存のターミナル試作で試せます。
スマホ用画面・オンライン対戦サイトはまだありません。

## ルール

空の正方形盤を使い、AとBが交互に3マスを埋めます。

- Aは直線3マス。縦・横を選べます。
- BはL字3マス。90度ずつ回転した4方向を選べます。
- 3マスすべてが盤内の空きマスなら、好きな場所に置けます。既存の駒に接する
  必要はありません。重ね置きは禁止です。
- 一度埋めたマスは、移動・撤去・奪取できません。色に関係なく以後は使用済みです。
- **自分の手番に、自分の形をどこにも置けなければ負け。相手の勝ちです。**
  パスや引き分けはありません。盤全体が埋まる必要もありません。

形の例（`■`が埋めるマス、`・`はこの形に含まれないマス）：

```text
A（直線）：■■■

B（L字）：
■■
■・
```

毎手必ず3マスが使えなくなり、有限の盤で手番を飛ばすこともできないため、
どの合法な進め方でも必ず有限手で勝敗がつきます。

## 2つの版

| | まず試す版 | 比較用の少し大きい版 |
|---|---|---|
| 盤面 | 7×7 | 9×9 |
| 先手 | **B（L字）** | **A（直線）** |
| 保存済み8局の結果 | A5勝・B3勝 | A4勝・B4勝 |
| 保存局の長さ | 12〜14手 | 18〜24手 |

手数は観測であり、ルールの打切り上限ではありません。
局と局の間で役割担当を交替しても、7×7はB先手、9×9はA先手というルールは変えません。
この2版は別の条件です。勝数を混ぜて公平性を判断しません。

## 紙で試す

7×7のマス目と、A/Bを区別できる筆記具があれば準備できます。
紙の盤はルールを理解する最小の方法で、合法手や終局を自動判定しません。
不明なときは、その手番の形を置ける空間がどこかに残っていないか確認してください。
この文書を作成したことで、紙で人間が試したことにはしていません。

## AIと試す（ターミナル）

リポジトリの場所に移動してから実行します。ここに記載した対局はまだ起動していません。

```sh
cd <LOCAL_WORKSPACE>
PYTHONPATH=src python3 -m parity_forge.finite_space_batch --play-rule experiments/prototypes/plan0032/tile-i-l-7-b-v0.json --human B
```

これは自分がB（L字）で先手、AIがA（直線）の7×7版です。
縦横の座標は左上が`0,0`。7×7では行・列とも0〜6です。
埋める3マスを、半角スペースで区切って入力します。

```text
0,0 0,1 1,0
```

この例は左上のL字です。Aの横向き直線なら、例えば`0,0 0,1 0,2`です。
盤面の`A`/`B`は使用済み、`.`は空きマスです。間違った入力は拒否されます。

人間をAにするには末尾を`--human A`に変更します。この場合も先手はBなので、
AIが先に置きます。`--human both`ならA/B両方を人間が入力するローカル操作です。
オンライン機能ではありません。外部テスターの募集や自動の対局記録収集は行いません。

9×9版を自分A・先手で試す場合は、次のコマンドです。

```sh
PYTHONPATH=src python3 -m parity_forge.finite_space_batch --play-rule experiments/prototypes/plan0032/tile-i-l-9-a-v0.json --human A
```

9×9の座標は0〜8です。終了したいときは自分の入力時に`q`。
時間や都合で途中終了した場合は「中断」であり、ゲームの引き分けにはしません。
AIはローカルの固定プログラムで、対局中にChatGPTや外部APIを呼びません。

## 今回だけのお願い

試すなら、合計20分以内で十分です。まず7×7を1局、余裕があれば同じ版で担当を
入れ替えてもう1局。9×9まで無理に試す必要はありません。
感想は自由な一言で構いません。「次に試したい手がある」「どこで負けたのか
分からない」「操作しづらい」など、実際に感じたことだけを教えてください。
こちらで楽しさ・上達・公平性の数値評価を勝手に作ることはしません。

## 分かっている弱点

- 9×9の4勝4敗は、方策を変えると勝者が逆転した結果です。公平性の証明ではありません。
- 今のAIは最大2手先までで、予算内に完了せず1手先の判断を使うこともあります。
  9×9/A先手の探索89判断中59、7×7/B先手の53判断中30は1手先まででした。
- 3手以内に終局しないことは確認済みですが、それ以上の簡単な必勝法や、強い
  プレイヤー間の偏りを否定できていません。限定レビューで明白な鏡映・固定手数
  パリティ等の万能戦略は見つからなかった、という範囲です。
- 初手の置き方が多く、迷いやすさ・座標入力の面倒さ・人間にとっての深さは未検証です。
  この段階で紙/ターミナルが合わなければ、その点も大切な結果です。

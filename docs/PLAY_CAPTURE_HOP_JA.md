# 捕獲と跳躍 — 暫定試遊版

2026-09-06追記：この候補の試遊推薦を撤回した。A先手に簡単な7手以内の
必勝方策がある。人間の評価を依頼する対象ではない。
[必勝証明と棄却理由](../experiments/reports/0021-short-win-proof-ja.md)。
以下は作成済み端末の利用記録として保存するもので、現在の推薦ではない。

AIと実際に対戦できる端末版。採用条件はA先手。
引き分けなしの終了は証明済みだが、公平性・奥深さ・面白さは未認定。
全体テストも実行中なので、現段階では完成品ではなく試遊用の候補。

## 起動

プロジェクトの端末で次を実行する。

```sh
PYTHONPATH=src python3 -m scripts.plan0021_play --first A --human A
```

盤面にA/Bが表示され、その下に合法手の番号が並ぶ。番号を入力してEnter。
座標は（行,列）で1始まり。`.`は空きマス。`q`で中断できる。
保存・通信・追加インストールは不要。

飛び越し役Bを担当する場合は、先手Aは変えずに`--human B`とする。
先手を入れ替えたB先手版は別条件で、今回の試遊基準を通っていない。

## ルール

- 5×5。上辺にAを5枚、下辺にBを5枚。Aから交互に1枚動かす。
- Aは下向き。前・斜め前の空きへ1マス進むか、そのマスにいるBを取る。
- Bは上向き。前・斜め前の空きへ1マス進む。隣に駒がある場合は、その先が
  盤内の空きなら、駒を1枚だけ飛び越せる。敵味方どちらでもよく、取らない。
  連続ジャンプはしない。
- 1枚でも反対側の辺へ着いたら勝ち。合法手がなくなった側は負け。
- 後退・横移動・パス・運はない。全合法手順で40手以内に勝敗がつく。

飛び越されたAは後ろへ戻れない。前へ進めることと、Bの出口を守ることの
両方を考える。これは遊び始めるヒントであり、必勝法ではない。

## 何が確認できているか

固定の機械検証は24局すべて目標到達で終了。1局9〜21手だった。
A先手の同程度設定AI同士では、乱数・2手読み・3手読みの各4局が
それぞれA3勝/B1勝。少数の自己対戦なので、公平性を認定しない。
両先手の厳密解析は各10万局面で打切り。簡単に解けないことの証明ではない。

試遊AIは既存の3手読み、各判断20,000ノード上限。人間の先生や十分強い
基準AIとは限らない。中断や計算上限はゲームの引き分けには数えない。
この端末での対戦は記録・集計せず、固定実験へ混ぜない。
